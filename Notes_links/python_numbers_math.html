02 / Fundamentals

Numbers & Math

Integers, Floats, Operators & Precedence Rules

Beginner15 min read

01 / Overview

Integers vs Floats

Python separates numbers into whole numbers (int) and decimals (float).

x = 10 # int
y = 10.5 # float
💡 Memory Tip

Any math operation involving a float automatically yields a float result.

02 / Basic Arithmetic

Basic Arithmetic

Standard operators handle everyday calculations seamlessly.

  • + Addition | - Subtraction
  • * Multiplication | / True Division
💀 Division Note

/ always returns a float (e.g., 4 / 2 = 2.0).

03 / Advanced Operators

Advanced Math Operators

Special division and power operators for complex IT problems:

f = 10 // 3 # Floor Div (3)
m = 10 % 3 # Modulo Remainder (1)
p = 2 ** 3 # Exponent (8)
⚡ Modulo Use

Modulo (%) is vital for checking even/odd numbers (n % 2 == 0).

04 / Precedence

Precedence & PEMDAS

Python follows strict operator precedence order during calculation evaluation.

res = (5 + 5) * 2 ** 2 # Parentheses first!
🎯 Best Practice

Always use parentheses () to make complex formulas readable and correct.

05 / Values

Negative numbers and absolute value

A minus sign can represent a negative value or subtraction. abs() returns the distance from zero without the sign.

temperature = -4
print(abs(temperature))
Output4

06 / Precision

Rounding decimal results

Division often creates a float. Use round(value, digits) when a displayed result needs a chosen number of decimal places.

price = 19.987
print(round(price, 2))
Output19.99

Rounding changes the returned value used in the expression; it does not change the original variable unless you assign it back.

07 / Conversion

Convert numeric text carefully

When numeric data is stored as text, int() creates a whole number and float() creates a decimal.

whole = int("12")
decimal = float("12.5")
print(whole + 3)

The text must contain a form the chosen type can understand.

08 / Common Mistakes

Check the operation and denominator

Wrong assumptionresult = 5 / 2
# result is 2
Correct resultresult = 5 / 2
# result is 2.5

True division returns a float. Dividing by zero is invalid, and int("2.5") cannot parse a decimal string directly.

09 / What You Learned

Numbers are predictable when types are clear

  • int stores whole numbers; float stores decimals.
  • Arithmetic includes /, //, %, and **.
  • Parentheses make evaluation order explicit.
  • abs() measures distance from zero and round() controls precision.
  • Convert numeric strings before doing math.
