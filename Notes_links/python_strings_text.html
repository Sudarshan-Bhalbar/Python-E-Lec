06 / Text

Strings & Text

Merged Reference Guide: Fundamentals, Slicing & In-Depth Built-In Methods

Beginner25 min read

01 / Fundamentals

String Creation & Quotes

Strings store text characters enclosed in single (') or double (") quotes.

msg = "Hello Python"
char = 'A'
💡 Flexibility Rule

Use opposite quotes if your text contains apostrophes (e.g., "It's working").

02 / Combining

Concatenation & Repetition

Use arithmetic operators to combine or repeat text patterns:

# Concatenation (+)
full = "Cyber" + "Security"
# Repetition (*)
dash = "-" * 10
💀 Warning

You cannot add strings and integers directly ("Score: " + 10 causes a crash).

03 / Access

Indexing & Slicing

Python strings are indexed starting at 0. Access specific segments using brackets:

text = "Python"
first = text[0] # 'P'
sub = text[0:2] # 'Py'
⚡ Negative Indexing

text[-1] fetches the very last character of any string!

04 / Case

upper() & lower()

Converts all characters in a string to uppercase or lowercase letters respectively.

text = "Python IT"
print(text.upper()) # "PYTHON IT"
print(text.lower()) # "python it"
🎯 Use Case

Great for normalizing user inputs (e.g., checking ans.lower() == 'yes').

05 / Cleanup

strip(), lstrip(), rstrip()

Removes leading and trailing whitespaces or specified characters from a string.

msg = " Hello World! "
print(msg.strip()) # "Hello World!"
print(msg.lstrip()) # Left strip only
💡 Data Cleanup

Essential when processing text data from files or user form submissions.

06 / Replace

replace(old, new)

Searches the string for a specified phrase and replaces all occurrences with a new phrase.

sentence = "I like cats"
res = sentence.replace("cats", "dogs")
print(res) # "I like dogs"
⚡ Parameters

You can add a third limit argument replace(old, new, count) to restrict changes.

07 / Search

find() & index()

Locates the starting position (index) of the first occurrence of a substring.

word = "Computer"
print(word.find("put")) # 3
# find() returns -1 if missing, index() crashes with ValueError
💀 Error Warning

Use find() if you aren't sure if the substring exists to avoid program crashes.

08 / Lists & Text

split() & join()

split() breaks a string into a list based on a separator. join() stitches a list back into a string.

text = "apple,banana,grape"
lst = text.split(",") # ['apple', 'banana', ...]
back = " ".join(lst) # 'apple banana grape'
🎯 Popular Combo

Extremely common in text processing, CSV parsing, and sentence word counts.

09 / Count

count(substring)

Returns the exact number of times a specified substring appears in the string.

phrase = "banana banana split"
print(phrase.count("banana")) # 2
💡 Sub-range Counting

You can define optional start and end bounds: count(sub, start, end).

10 / Prefix & Suffix

startswith() & endswith()

Checks whether a string begins or ends with specific characters, returning True or False.

filename = "report.pdf"
print(filename.endswith(".pdf")) # True
print(filename.startswith("re")) # True
⚡ File Validation

Standard approach for validating file extensions or URL prefixes in scripts.

11 / Validation

isdigit() & isalpha()

Inspects the contents of a string to check character classifications.

print("12345".isdigit()) # True (Only numbers)
print("Python".isalpha()) # True (Only letters)
print("Python3".isalnum()) # True (Letters + numbers)
💀 Input Check

Always verify inputs before casting strings to integers to prevent runtime crashes.

12 / Formatting

f-Strings & len()

Measures string length using len() and embeds variables cleanly using f-strings.

s = "hello"
print(len(s)) # Length (5)
print(f"Length is {len(s)}") # f-string formatting
🎯 Modern Standard

f-strings are the fastest and cleanest way to inject variables directly into text output.
