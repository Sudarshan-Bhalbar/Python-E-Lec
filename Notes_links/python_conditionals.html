06 / Control Flow

Conditional Statements

Choose a branch with if, elif, and else by combining comparisons, booleans, and indentation.

Beginner26 min read

01 / Overview

Programs make choices

Conditional statements decide which block of code should run. Python evaluates a condition as True or False, then follows the matching branch.

condition→True / False→chosen branch

02 / if

Run a block only when true

if score >= 40:
    print("Passed")

The colon starts the block, and four spaces show which statement belongs to it. If the comparison is false, Python skips the block.

03 / Two Branches

Choose if or else

if age >= 18:
    print("Adult")
else:
    print("Minor")
age >= 18?
↙ yes     no ↘
Adult     Minor

04 / Multiple Branches

Test an elif ladder

if marks >= 85:
    grade = "A"
elif marks >= 60:
    grade = "B"
else:
    grade = "C"

Python stops at the first true branch. Put more restrictive conditions before broader ones.

05 / Boolean Conditions

Combine earlier logic tools

if age >= 18 and has_id:
    print("Enter")

Comparisons create boolean values, and and, or, and not combine them into a decision.

06 / Nesting

Check a dependent condition

if logged_in:
    if is_admin:
        print("Admin panel")

A nested block belongs to the outer block. Keep nesting shallow and combine simple conditions when that makes the rule clearer.

07 / Ordering

Order branches from narrow to broad

Because an elif ladder stops at the first match, a broad condition placed first can prevent a later specific branch from ever running.

if marks >= 85Most specific grade rule first.
elif marks >= 60Broader rule after the specific one.

08 / Shorthand

Use a simple conditional expression

status = "Adult" if age >= 18 else "Minor"

This one-line form is useful for a short value choice. Use a normal if/else block when the logic needs multiple statements.

09 / Common Mistakes

Colons and indentation are syntax

Wrongif score > 5
print("Pass")
Correctif score > 5:
    print("Pass")

Every header needs a colon, and every block statement needs consistent indentation.

10 / What You Learned

Decisions are readable branches

  • if runs code when a condition is true.
  • elif tests another branch only when earlier ones failed.
  • else is the fallback branch.
  • Indentation defines each block.
  • Branch order changes the result.
