Complete Decision-Making Guide: if, elif, else, Nested Blocks & Flowcharts

1. The Basic if Statement

Used to test a specific condition. If the boolean expression evaluates to True, the indented block runs; otherwise, it is skipped.

if score >= 40:
    print("Passed!")

Execution Flow Diagram:

Condition: score >= 40
⬇ (If True)
Execute indented print() block
💡 Indentation Rule

Python uses 4 spaces of indentation instead of curly braces {} to group code blocks.

2. The if-else Dual Branch

Provides an alternative backup block of code that automatically executes if the initial if condition turns out to be False.

if age >= 18:
    print("Adult")
else:
    print("Minor")

Flow Diagram:

Condition True?
↙ (True)      ↘ (False)
Run if block    Run else block
💀 Syntax Trap

Never forget the colon (:) at the end of every if, elif, and else statement line!

3. Multi-Branch Ladder (elif)

Allows testing multiple sequential conditions one by one until a match is found. Once a branch evaluates to True, Python skips the rest.

if marks >= 85: grade = "A"
elif marks >= 60: grade = "B"
else: grade = "C"

Ladder Evaluation Flow:

Check 1 (if) ➔ False
⬇
Check 2 (elif) ➔ True ✅
⬇ (Stops testing further)
Execute Grade B Branch
⚡ Order Matters

Always arrange conditions from most restrictive to least restrictive in an elif ladder.

4. Nested Conditionals

Placing an entire if statement inside another if block to check dependent secondary conditions.

if logged_in:
    if is_admin:
        print("Welcome Admin Panel")

Dependency Diagram:

Outer Check: logged_in? (True)
⬇
Inner Check: is_admin? (True)
⬇
Execute Inner Action
🎯 Clean Code Tip

Avoid deep nesting by combining conditions using logical operators like and.

5. Ternary Operator (Shorthand)

A compact, single-line alternative for simple if-else assignments.

# Syntax: [on_true] if [cond] else [on_false]
status = "Adult" if age >= 18 else "Minor"

Inline Logic Flow:

Evaluate: age >= 18
↙ (True)      ↘ (False)
Returns "Adult"    Returns "Minor"
💡 Readability Check

Great for simple value assignments, but avoid using it for long complex blocks of code.

6. Common Gotchas & Best Practices

Review frequent mistakes student programmers make when writing conditional logic:

# IndentationError trap:
if x > 5:
print("Oops, missing space indentation!")

Checklist:

  • Always verify indentation depth (consistent 4 spaces).
  • Make sure variable names match casing rules.
  • Ensure logical expressions evaluate cleanly to booleans.
💀 Crash Prevention

Watch out for type mismatch errors when comparing user strings against numbers!
