1. Comparison Operators

Evaluate two values and return a boolean (True or False).

  • == Equal to | != Not equal
  • > Greater | < Less than
  • >= Greater or equal | <= Less or equal
💀 Common Bug

Never mix up assignment (=) with comparison (==)!

2. Logical Operators

Combine multiple conditions into advanced logical checks:

and: True if both are true.
or: True if at least one is true.
not: Reverses boolean state.
💡 Range Example

(x >= 10) and (x <= 50) checks if x is inside a boundary range.

3. In-Place Assignment

Shorthand operators update a variable's value based on its current state.

score += 10 # Same as score = score + 10
health -= 20 # Same as health = health - 20
⚡ Productivity Tip

Also works with multiplication (*=) and division (/=).

4. Operator Priority

Evaluation hierarchy matters when mixing arithmetic and logic.

  • 1. Arithmetic Math (+, *, **)
  • 2. Comparisons (==, >)
  • 3. Logic Gate (not, and, or)
🎯 Pro Rule

Wrap separate comparison clauses in parentheses () to prevent logic bugs.
