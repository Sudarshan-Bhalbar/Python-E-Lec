04 / Fundamentals

Operators & Logic

Calculate values, compare them, and combine boolean results into clear decisions.

Beginner24 min read

01 / Overview

Operators describe an action

An operator tells Python how to combine or compare values. Arithmetic operators produce numbers; comparison and logical operators produce booleans.

values→operator→result

02 / Arithmetic

Calculate with numbers

+ - *

Add, subtract, and multiply.

/ //

True divide or floor divide.

%

Find a remainder.

**

Raise to a power.

total = 10 + 3
remainder = 10 % 3

Choose the operator that describes the result you need, especially when division should stay whole.

03 / Comparison

Ask a yes-or-no question

is_big = 10 > 5
same = 3 == 3
Valuesis_big → True
same → True

Comparison operators include ==, !=, >, <, >=, and <=.

04 / Assignment

Update a value in place

score = 10
score += 5
score *= 2

score += 5 means score = score + 5. The same idea works with -=, *=, and /=.

05 / Logic

Combine boolean results

and

Both expressions must be true.

or

At least one expression is true.

not

Reverse a boolean result.

allowed = age >= 18 and has_id

Parentheses can make each comparison boundary visible.

06 / Precedence

Make evaluation order visible

Python evaluates arithmetic before comparisons, and comparisons before logical combinations. Parentheses override that order.

ready = (score >= 70) and (attempts < 3)

Write separate comparisons in parentheses when a condition has more than one part.

07 / Useful Patterns

Read conditions as sentences

age >= 18“age is at least 18.”
score != 0“score is not zero.”
10 <= value <= 50Chained comparison for a range.

08 / Common Mistakes

Do not confuse assignment and comparison

Wrong for a questionif score = 10:
Correct comparisonif score == 10:

A single = assigns. Double == compares. Also avoid relying on precedence when parentheses can clarify the intention.

09 / What You Learned

Logic is built from small results

  • Arithmetic operators calculate.
  • Comparisons return True or False.
  • Assignment shortcuts update existing values.
  • and, or, and not combine logic.
  • Parentheses make complex expressions easier to read.
