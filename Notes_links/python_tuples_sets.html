10 / Collections

Tuples & Sets

Choose ordered immutable data or unique membership-focused data for the job at hand.

Beginner22 min read

01 / Overview

Two useful collection shapes

A tuple keeps values in a fixed order. A set keeps unique values and is designed for membership and set operations rather than positions.

Tuple

Ordered, indexable, and immutable.

Set

Unique items with fast membership checks.

02 / Tuples

Ordered and immutable

point = (10, 20)
print(point[0])
Output10

Parentheses commonly create a tuple. You can read by index, but you cannot replace an item after creation.

💡 One-item tuple

A one-item tuple needs a comma: single = (42,).

03 / Tuple Patterns

Unpack related values

Tuple unpacking assigns each position to a matching variable.

point = (10, 20)
x, y = point
print(x)
print(y)

The number of names should match the number of values. This pattern is useful for coordinates and small fixed records.

04 / Sets

Unique values, no positional index

unique = {1, 2, 2, 3}
print(unique)
print(2 in unique)
Output{1, 2, 3}
True

The repeated 2 is stored once. Sets do not provide list-style positions such as unique[0].

05 / Set Operations

Combine and change sets

add(value)Add one unique item.
remove(value)Remove an item; missing items cause an error.
discard(value)Remove an item without that missing-item error.
union(other)Combine all unique items.
intersection(other)Keep items shared by both sets.
difference(other)Keep items only in the first set.

06 / Choose Well

List vs tuple vs set

List

Use when order matters and values may change.

Tuple

Use for a fixed ordered group of values.

Set

Use when duplicates should disappear or membership matters.

Choosing the right shape communicates how the data is meant to behave.

07 / Useful Patterns

Membership and shared values

required = {"name", "email"}
received = {"name", "email", "phone"}
print(required.intersection(received))

Set operations make “what do these groups share?” easy to express without manually comparing every value.

08 / Common Mistakes

Know the behavior you chose

Wrongpoint = (10, 20)
point[0] = 99
Correctpoint = (99, 20)
# create a new tuple

Tuples cannot be changed in place. Also avoid expecting a set to preserve a meaningful display order.

09 / Do & Don't

Use each collection honestly

Do

Use a set for uniqueness and a tuple for a fixed record.

Don't

Use a set when you need index positions or rely on its printed order.

10 / What You Learned

Collection choice becomes clearer

  • Tuples are ordered and immutable.
  • Tuple indexes and unpacking read fixed data.
  • Sets remove duplicates and support membership.
  • Set methods combine or remove unique values.
  • Lists, tuples, and sets solve different collection problems.
