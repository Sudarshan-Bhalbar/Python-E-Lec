07 / Control Flow

While Loops

Repeat work while a condition stays true, then stop cleanly when the job is done.

Beginner20 min read

01 / Overview

Iteration with a condition

A while loop repeats an indented block as long as its condition evaluates to True. It is useful when you know the stopping rule but not necessarily the exact number of repetitions.

check condition→run body→update state
💡 Core idea

Every useful while loop needs a condition that can eventually become false.

02 / First Example

Count from one to three

Start with a counter, check it, print it, and then change it before the next check.

count = 1
while count <= 3:
    print(count)
    count += 1
Output1
2
3

Why it works: Python checks count <= 3 before each pass. The update makes the fourth check false, so the loop ends.

03 / Execution Flow

Check, run, repeat

The condition is checked before the body. If it is false on the first check, the body runs zero times.

Is the condition True?
⬇ yes
Run the indented body
⬆ update, then check again
Stop when the condition is False

This is different from “repeat exactly five times”: the condition controls the number of passes.

04 / Syntax & Rules

The loop header and body

while condition:
    statement
    statement
  • Write while, then a boolean condition, then a colon.
  • Indent every statement that belongs to the loop by four spaces.
  • Use a variable that changes or a condition that can naturally end.
⚠ Indentation matters

Only the indented lines repeat. A line aligned with while runs after the loop.

05 / Loop Control

break and continue

break exits the loop immediately. continue skips the rest of the current pass and returns to the next condition check.

break

Use when the job is complete or a stop condition is found.

continue

Use when the current pass should be skipped.

n = 1
while n <= 5:
    if n == 3:
        break
    print(n)
    n += 1

06 / Useful Patterns

Counter and sentinel loops

count = 0Use a counter when each pass moves toward a known boundary.
while answer != "quit":Use a sentinel value when the user or program chooses when to stop.
total += valueUpdate an accumulator inside the loop to build a result.

Keep the condition and the state update close together so the stopping rule is easy to inspect.

07 / Common Mistakes

Prevent runaway loops

Wrongcount = 1
while count <= 3:
    print(count)
Correctcount = 1
while count <= 3:
    print(count)
    count += 1

The wrong version never changes count, so its condition never becomes false. That creates an infinite loop.

Watch for

Missing updates, wrong comparison signs, and indentation that places an update outside the loop.

08 / Do & Don't

Make the stopping rule obvious

Do

Give counters meaningful names and update them in a predictable direction.

Don't

Hide the only state update in a distant branch where it may never run.

09 / Quick Recap

While loops in five ideas

  • Python checks the condition before each pass.
  • The indented body repeats while the condition is true.
  • State must change so the loop can finish.
  • break stops; continue skips.
  • While loops can be counter-based or sentinel-based.
