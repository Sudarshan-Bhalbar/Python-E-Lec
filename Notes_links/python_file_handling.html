14 / Input & Output

File Handling

Read and write text files safely, choose the right mode, and close resources cleanly.

Beginner+25 min read

01 / Overview

Persistent text outside the program

Variables disappear when a program ends. A text file stores information on disk so another run can read it later.

file path→open→read or write→close

Python represents an opened file with a file object that provides methods for moving text in and out.

02 / Open

Choose a path and mode

file = open("notes.txt", "r")
text = file.read()
file.close()

open() receives a path and a mode. The returned object is used for reading or writing until it is closed.

💡 Resource rule

Always close a file you opened manually, even when the program only reads it.

03 / Read

Read all or read by line

read()Read the remaining text as one string.
readline()Read one line.
readlines()Read lines as a list of strings.
with open("notes.txt", "r") as file:
    text = file.read()

Reading gives you a string or a list of lines, which you can inspect with the String and List tools already learned.

04 / Write

Create or replace text

with open("notes.txt", "w") as file:
    file.write("Hello Python")

Write mode creates a missing file and replaces existing contents. Use it when replacement is intentional.

⚠ Destructive mode

Opening an existing file with "w" clears its old contents before writing.

05 / Modes

r, w, and a

r · read

Read existing text. This is the default mode.

w · write

Replace contents or create a file.

a · append

Add new text to the end without replacing old text.

with open("log.txt", "a") as log:
    log.write("started\n")

06 / Safe Closing

Let with manage the close

The with statement opens the file for the indented block and closes it when that block finishes. It is the preferred pattern for normal file work.

Open resource
⬇

⬇
Close resource automatically

07 / Paths

Be precise about filenames

A relative path is resolved from the program's current working folder. A filename such as data.txt means a file in that location.

"data.txt"Simple relative file in the current folder.
"logs/today.txt"File inside a relative subfolder.

Keep paths clear and use the correct spelling and extension.

08 / Common Mistakes

Protect the file lifecycle

Riskyfile = open("notes.txt", "w")
file.write("new")
Saferwith open("notes.txt", "w") as file:
    file.write("new")

Use the correct mode, keep work inside the indented block, and do not forget that write mode replaces old contents.

09 / What You Learned

Files are a simple data boundary

  • open() connects code to a path.
  • read(), readline(), and readlines() retrieve text.
  • write() stores text.
  • r, w, and a choose behavior.
  • with closes the file automatically.
