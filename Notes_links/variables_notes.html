1. Anatomy & Memory

A variable is a sticky label pointing to an object in memory using =.

score = 100
Label: score
⬇
Memory Address: Integer 100
💡 Core Rule

Variables are created instantly the moment you assign a value!

2. Naming Rules & Style

Must start with letter/underscore. Case-sensitive (Age ≠ age).

  • Valid: letters, numbers, _
  • PEP 8 Standard: Use snake_case (e.g., user_score).
💀 Invalid Examples

1st_score (starts with number ❌)

3. Dynamic Typing

Python variables don't lock to a fixed type; objects in memory do.

x = 50 # int
x = "Hello" # str

You can freely reassign variables across different data types.

⚡ Type Checking

Use built-in type(variable) to inspect current object types.

4. Advanced Assignment

Shorthand syntaxes to manage variables efficiently in single lines.

x, y = 10, 20 # Multiple
a = b = 100 # Chained

Constants use ALL_CAPS by convention to warn against changes.

🎯 Pro Swap Trick

Swap values instantly: a, b = b, a
