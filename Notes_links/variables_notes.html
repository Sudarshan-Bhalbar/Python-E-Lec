01 / Fundamentals

Variables in Python

Store, change, and work with values in Python — the first building block for every useful program.

Beginner20 min read

01 / Overview

A name that points to a value

A variable is a sticky label pointing to an object in memory using =. Python creates the variable the moment an assignment runs; there is no separate declaration step.

score = 100
labelname“Ava”
valueage14
Label: score→ Integer 100
💡 Core rule

Variables are created instantly the moment you assign a value!

02 / First example

Give values useful names

Good names make code readable before you even run it. A variable can hold a number, text, or any other value supported by the program.

name = "Ava"
age = 14
print(name)
print(age)
OutputAva
14

03 / How variables work

Assignment can change the label

Python variables do not lock to a fixed type; objects in memory do. Reassigning a name makes it point to a new value, even when that value has a different type.

x = 50       # int
x = "Hello"  # str

You can freely reassign variables across different data types. Use built-in type(variable) to inspect the current object type.

⚡ Type checking

The name x stays the same, but the value it refers to can change.

04 / Syntax

Read assignment from right to left

The expression on the right is evaluated first, then the result is stored under the name on the left.

name = expressionvalue → label
total = 17 + 3  # stores 20
print(total)
Output20

05 / Naming rules

Names should be valid and clear

Variable names must start with a letter or underscore. They are case-sensitive: Age ≠ age.

  • Valid characters: letters, numbers, and _
  • PEP 8 standard: use snake_case, such as user_score
  • Choose names that describe the value, not just its position

✓ Valid

user_name
score2

✕ Invalid

1st_score
Starts with a number.

06 / Values & types

Python keeps track of the type

Integers, decimals, strings, and booleans are all values a variable can hold. Python uses the current value to determine its type at runtime.

age = 14          # int
temperature = 21.5  # float
is_ready = True  # bool

Inspect a value with type(variable) when you need to understand what Python is holding.

07 / Useful patterns

Change and combine values efficiently

These patterns build directly on assignment and are useful once you are comfortable reading a variable’s current value.

score = score + 1Updates the value by adding one.
x, y = 10, 20Assigns multiple values in one line.
a = b = 100Chained assignment gives both names the same value.
a, b = b, aSwaps values instantly without a temporary variable.

Constants use ALL_CAPS by convention to warn against changes.

09 / Quick recap

Do this, not that

Do

Use descriptive variable names such as student_name.

Don’t

Use unclear names like x1 unless the context makes the meaning obvious.

What you learned

Variables are labels, assignment stores values, Python is dynamically typed, and clear names make your programs easier to understand.
