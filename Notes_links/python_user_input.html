1. The input() Function

Used to prompt users in the terminal and capture keyboard data interactively.

name = input("Enter your name: ")
💡 Core Rule

Execution pauses completely until the user types text and presses Enter.

2. The String Trap

The input() function always returns data as a string (str), even numbers!

age = input("Age: ") # Returns str
💀 Danger Zone

Trying to do math on raw input results in a TypeError.

3. Type Casting Wrapper

Convert text inputs into numbers using wrapper functions immediately.

raw = input("Score: ")
score = int(raw) # Cast to int
input() ➔ String
⬇
int() or float() Casting
⬇
Ready for Math! ✅

4. Inline Casting Shortcut

Experienced developers wrap the input function directly inside the type caster to save lines.

price = float(input("Enter price: "))
⚡ Pro Tip

Always validate or wrap inputs when building numerical scripts to avoid crashes.
