03 / Interaction

User Input & Interaction

Prompt users, capture keyboard input, convert values, and build small interactive programs.

Beginner22 min read

01 / Overview

Programs can ask for data

input() pauses the program, displays an optional prompt, and returns what the user types after pressing Enter.

prompt→user types→text value

Store the result in a variable so later lines can use it.

02 / First Example

Ask a clear question

name = input("What is your name? ")
print("Hello,", name)

The prompt is the message inside the parentheses. The value returned by input() is assigned to name, then printed.

03 / Core Rule

input() always returns text

age = input("Age: ")
print(type(age))
Output for 14<class 'str'>

Even if the user types digits, Python receives characters. That is why adding an input value directly to a number does not perform numeric math.

04 / Conversion

Convert before doing math

raw = input("Score: ")
score = int(raw)
print(score + 5)

Use int() for whole numbers and float() for decimals. The conversion happens after the text arrives.

05 / Variables

Store several answers

first = input("First name: ")
city = input("City: ")
print(first, "lives in", city)

Each call can have its own variable. Use names that describe the answer so the later output reads like a sentence.

06 / Small Program

Combine prompt, conversion, and output

name = input("Name: ")
year = int(input("Birth year: "))
print(name, year)

The inner input() runs first, then int() converts its returned text. Keep each step visible while learning.

07 / Input Quality

Validation starts with a clear rule

Before advanced error handling, define what acceptable input looks like: non-empty text, a whole number, or a value within a range. Conditions can then check simple rules.

name = input("Name: ")
if name == "":
    print("A name is required")

08 / Common Mistakes

Keep text and numbers distinct

Wrongage = input("Age: ")
print(age + 1)
Correctage = int(input("Age: "))
print(age + 1)

Raw input is text. Convert it once, close to where it enters the program, before arithmetic.

09 / What You Learned

Interaction is a simple data pipeline

  • input() displays a prompt and waits for Enter.
  • Its return value is always a string.
  • Store answers in descriptive variables.
  • Use int() or float() before numeric work.
  • Define input rules before adding more advanced handling.
