09 / Collections

Lists & Arrays

Store ordered values, change them safely, and work through collections one item at a time.

Beginner28 min read

01 / Overview

One name for many values

A list is an ordered, changeable collection. It keeps values in positions called indexes, starting at zero.

colors = ["red", "green", "blue"]
list→index 0→value

Python lists are often used where a beginner might call something an “array”: a group of related values handled together.

02 / First Example

Create and read a list

items = ["Pen", "Book"]
print(items[0])
print(items[1])
OutputPen
Book

Square brackets create the list. The first value is at index 0, not index 1.

03 / Access

Indexing and slicing

Use an index for one item and a slice for a range. Negative indexes count from the end.

scores = [80, 90, 75, 88]
print(scores[-1])
print(scores[1:3])

scores[-1] is 88. The slice contains indexes 1 and 2; its stop index is exclusive.

04 / Core Rule

Lists are mutable

Mutable means the list can change after it is created. Assign to an index when you need to replace one item.

items = ["Pen", "Book"]
items[1] = "Scale"
print(items)
Output['Pen', 'Scale']

Changing the item does not create a new variable; it updates the existing list.

05 / Methods

Change the collection

append(value)Add one item at the end.
extend(values)Add each item from another collection.
insert(index, value)Place an item at a position.
remove(value)Remove the first matching value.
pop(index)Remove and return an item; without an index, use the last item.
clear()Remove every item.

06 / Inspect & Order

Find, count, sort, and reverse

index(value)Find the first matching position.
count(value)Count matching items.
sort()Order the list in place.
reverse()Reverse the current order.
copy()Create a shallow copy of the list.

Methods such as sort() and reverse() change the list and return no useful list value.

07 / Useful Patterns

Combine lists with known loops

total = 0
for score in [10, 20, 30]:
    total += score
print(total)
Output60

Access, update, and iterate over a list with the same variables and loop rules you already know.

08 / Common Mistakes

Respect indexes and return values

Wrongitems = ["a", "b"]
print(items[2])
Correctitems = ["a", "b"]
print(items[1])

Index 2 is outside a two-item list. Also remember that append() changes the list; it does not return the new list.

09 / Do & Don't

Choose clear collection operations

Do

Use descriptive names, check indexes, and use copy() when a separate list is needed.

Don't

Assume a list starts at 1 or sort it accidentally when the original order matters.

10 / Quick Recap

You now know lists

  • Lists use square brackets and zero-based indexes.
  • Slices use start:stop and exclude the stop.
  • Lists are mutable.
  • Methods add, remove, inspect, and reorder values.
  • Lists work naturally with for loops.
