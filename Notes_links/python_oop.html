16 / Program Design

Object-Oriented Programming

Model related data and behavior with classes, instances, attributes, and methods.

Intermediate32 min read

01 / Overview

Objects group data and behavior

Object-oriented programming models a thing as an object with attributes (data) and methods (behavior). A class is the reusable design; an instance is one concrete object made from that design.

class blueprint→instance→attributes + methods

Use a class when values and the actions that use those values belong together.

02 / First Example

Define a class and create an instance

class Player:
    def __init__(self, name):
        self.name = name

hero = Player("Ava")
print(hero.name)
OutputAva

Player is the class. hero is one instance. The constructor stores the argument on that instance.

03 / __init__ & self

Initialize each object

__init__ runs when an instance is created. The first parameter, conventionally called self, refers to the current instance.

class Counter:
    def __init__(self, start):
        self.value = start

one = Counter(5)
print(one.value)

self.value belongs to the object, while start is the incoming parameter.

04 / Attributes

Store state on the instance

class Lamp:
    def __init__(self, color):
        self.color = color
        self.is_on = False

Attributes are the named values that describe one object. Two Lamp instances can have different colors and states while sharing the same class design.

05 / Methods

Give objects useful actions

class Lamp:
    def switch_on(self):
        self.is_on = True

lamp.switch_on()
print(lamp.is_on)

A method is a function defined inside a class. Calling lamp.switch_on() lets the method update that particular lamp through self.

06 / Encapsulation

Keep state changes meaningful

Beginner-level encapsulation means keeping related state and the operations that change it together. Prefer a method such as deposit() over scattering raw state changes throughout a program.

account.deposit(50)The object owns the action and can keep its rules in one place.
account.balanceThe object exposes the value a caller needs to read.

07 / Inheritance

Reuse a related class carefully

class Animal:
    def speak(self):
        print("sound")

class Dog(Animal):
    pass

Dog inherits the behavior of Animal. Start with inheritance only when the relationship is genuinely “is a kind of”; otherwise, a separate class may be clearer.

08 / Common Mistakes

Respect instance structure

Wrongclass Player:
    def init(name):
        name = name
Correctclass Player:
    def __init__(self, name):
        self.name = name

Use the exact special method name, include self, and store instance data on self.

09 / Do & Don't

Design small, understandable classes

Do

Give each class a clear responsibility and each method a focused action.

Don't

Create inheritance chains or classes when a simple function and variables would be clearer.

10 / What You Learned

You can model a small object

  • A class is a reusable blueprint.
  • An instance is one object made from the class.
  • __init__ initializes attributes.
  • self identifies the current instance.
  • Methods provide behavior; inheritance can reuse a related design.
