08 / Control Flow

For Loops & Ranges

Visit each item in order, generate clean number sequences, and repeat work predictably.

Beginner22 min read

01 / Overview

Iteration over items

A for loop takes one item at a time from an iterable, assigns it to a loop variable, and runs the indented body.

iterable→current item→body→next item

At this level, strings and range() are useful, predictable things to iterate over.

02 / First Example

Visit each character

for letter in "cat":
    print(letter)
Outputc
a
t

Python places c, then a, then t in letter. The body runs once per character.

03 / range()

Generate number sequences

range() produces a sequence of numbers without requiring you to type every value.

range(stop)

Starts at 0 and stops before stop.

range(start, stop)

Starts at start, stops before stop.

range(start, stop, step)

Moves by the chosen step, including negative steps.

for number in range(1, 4):
    print(number)

Output: 1, 2, 3. The stop value is exclusive.

04 / Syntax & Rules

Read the loop header

for item in iterable:
    statement
  • The loop variable receives a new item on each pass.
  • in connects the variable to the iterable.
  • The colon starts the indented body.
  • The loop ends after the last item is visited.

05 / Useful Patterns

Counting and stepping

for i in range(5):Run five passes with values 0 through 4.
for i in range(2, 11, 2):Visit even values from 2 through 10.
for letter in word:Process text one character at a time.

Choose a descriptive loop variable when the value has meaning, such as day or letter.

06 / Loop Control

break and continue still apply

Use break to leave a for loop early and continue to skip the rest of one pass.

for number in range(1, 6):
    if number == 4:
        break
    print(number)

07 / Common Mistakes

Remember the exclusive stop

Wrong expectationrange(1, 4)
# expects 1, 2, 3, 4
Correct resultrange(1, 4)
# produces 1, 2, 3

The stop number is not included. Also check indentation: an unindented statement is outside the loop.

08 / Do & Don't

Keep iteration readable

Do

Use range() for predictable counts and name the current item clearly.

Don't

Use confusing manual counters when the loop already gives you the current value.

09 / Quick Recap

For loops in five ideas

  • A for loop visits items one at a time.
  • range() creates number sequences.
  • The stop value is exclusive.
  • Start, stop, and step control the sequence.
  • break and continue control passes.

10 / What You Learned

You can now trace each pass

You can write for loops over text, generate ranges, explain the current item, and use the workspace to test sequence boundaries.
