12 / Reusable Code

Functions & Return Values

Package a repeated idea once, give it inputs, and return a result you can use anywhere.

Beginner30 min read

01 / Overview

Give a name to a reusable job

A function is a named block of code that performs a focused task. Functions reduce repetition and make a program easier to read and change.

arguments→function→return value

Define a function once, then call it whenever that job is needed.

02 / First Example

Define, call, and return

def add(a, b):
    return a + b

result = add(5, 7)
print(result)
Output12

def creates the function. The call supplies 5 and 7 as arguments. return sends 12 back to the caller.

03 / Syntax & Rules

Read the function shape

def function_name(parameter):
    statement
    return value
  • Use a valid name after def and parentheses for parameters.
  • Finish the header with a colon and indent the body.
  • The function body does not run until the function is called.
  • A function without return returns None implicitly.

04 / Inputs

Parameters and arguments

A parameter is the name inside the definition. An argument is the value supplied by a call.

def greet(name, age):
    print("Hello", name)
    print(age)

greet("Ava", 14)

Positional arguments fill parameters from left to right. Keep calls in the same order unless you intentionally use named arguments.

05 / Results

Return values travel back

def double(number):
    return number * 2

answer = double(6)

return ends the function immediately and gives its expression to the caller. Store it, print it, or use it in another calculation.

06 / Scope

Local names stay local

A parameter and a variable created inside a function normally belong to that function. They are not automatically available outside it.

def make_total():
    total = 10 + 5
    return total

print(make_total())
💡 Naming tip

Pass values in and return values out instead of depending on hidden changes.

07 / Useful Patterns

Small functions compose well

def area(width, height):Keep one responsibility in one function.
return width * heightReturn a result instead of printing when another part may need it.
def greet(name="friend"):Default arguments provide a fallback value.

08 / Common Mistakes

Separate definition from call

Wrongdef add(a, b):
return a + b
Correctdef add(a, b):
    return a + b

Function bodies need indentation. Also avoid confusing print(), which displays a value, with return, which sends a value back.

09 / Do & Don't

Make functions easy to trust

Do

Use clear names, focused bodies, and explicit return values.

Don't

Write one enormous function that prints, changes, and calculates unrelated things.

10 / What You Learned

Reusable logic is now familiar

  • def defines a function.
  • Parameters receive arguments.
  • The body runs only when called.
  • return sends a result to the caller.
  • Local names belong to the function.
