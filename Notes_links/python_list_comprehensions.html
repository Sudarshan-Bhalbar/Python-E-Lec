13 / Collections

List Comprehensions

Build small transformed lists in one readable expression, while keeping the loop idea visible.

Beginner+20 min read

01 / Overview

A compact list-building pattern

A list comprehension creates a new list by visiting an iterable, evaluating an expression for each item, and optionally filtering items with a condition.

expressionforiteminiterable

It is a shortcut for a simple loop that appends results to a list.

02 / First Example

Transform each number

nums = [1, 2, 3, 4]
doubled = [n * 2 for n in nums]
print(doubled)
Output[2, 4, 6, 8]

For each n, Python calculates n * 2 and places that result in a new list.

03 / Syntax

Read left to right

[expression for item in iterable]
Expression

What goes into the new list.

Item

The current value from the source.

Iterable

The list, string, or range to visit.

The result is always a new list; the original iterable is not changed by the comprehension itself.

04 / Conditions

Filter with if

even = [n for n in range(1, 7) if n % 2 == 0]
print(even)
Output[2, 4, 6]

The if appears after the iterable. Only items passing the condition contribute a result.

05 / Compare

Every comprehension has a simple loop idea

# Comprehension
squares = [n * n for n in nums]

# Equivalent loop
squares = []
for n in nums:
    squares.append(n * n)

Knowing the longer form makes the shorter form easier to debug and explain.

06 / Useful Patterns

Transform text and numbers

[word.upper() for word in words]Transform each string after earlier Strings lessons.
[n + 1 for n in nums]Make a new numeric sequence without changing the original.
[n for n in nums if n > 0]Keep only values that pass a condition.

07 / Readability

Short is not always clearer

Use a comprehension when the expression and condition fit comfortably on one line. Prefer a regular loop when the body needs several steps, nested decisions, or a comment to explain it.

🎯 Rule of thumb

If you cannot explain the comprehension in one breath, expand it into a loop.

08 / Common Mistakes

Place the pieces correctly

Wrong[n for n in nums if n % 2]
Correct when selecting evens[n for n in nums if n % 2 == 0]

A condition that returns an odd remainder selects odd values. Also check that the expression is what you want to store, not merely the original item.

09 / Do & Don't

Keep one idea per line

Do

Use simple expressions and meaningful variable names.

Don't

Pack multiple nested loops or unrelated conditions into a hard-to-read line.

10 / What You Learned

Concise list building is ready

  • A comprehension creates a new list.
  • The expression comes before for.
  • The loop visits each source item.
  • An optional if filters results.
  • A regular loop is the readable fallback.
