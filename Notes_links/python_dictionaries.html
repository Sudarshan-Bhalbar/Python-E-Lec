11 / Collections

Dictionaries

Connect meaningful keys to values so records are easy to read, update, and search.

Beginner28 min read

01 / Overview

Labels instead of positions

A dictionary stores key-value pairs. The key describes what a value means, which makes dictionaries a natural fit for records such as a user profile.

key→value→meaningful record

Unlike a list, you usually look up dictionary data by a key rather than by a numeric index.

02 / First Example

Create and read a record

user = {"name": "Dev", "age": 21}
print(user["name"])
print(user["age"])
OutputDev
21

Colons separate keys from values, and commas separate pairs.

03 / Access

Read safely with get()

Square brackets are direct and useful when the key must exist. get() is safer when a key may be missing.

user = {"name": "Dev"}
print(user.get("email", "Not provided"))
OutputNot provided

The second argument is a fallback value; it keeps the lookup understandable without changing the dictionary.

04 / Update

Add and change pairs

user["age"] = 22
user["city"] = "Pune"
user.update({"active": True})

Assigning to an existing key changes its value. Assigning a new key adds a new pair. update() changes several pairs at once.

05 / Methods

Inspect dictionary data

keys()Return the keys.
values()Return the values.
items()Return key-value pairs.
pop(key)Remove and return one value.
clear()Remove all pairs.
copy()Make a shallow copy.

06 / Membership

Check whether a key exists

if "name" in user:
    print("Name is available")

The in operator checks keys in a dictionary. It does not search values by default.

07 / Useful Patterns

Loop through keys and values

for key, value in user.items():
    print(key, value)

items() gives two values per pass, so tuple unpacking names them as key and value.

🎯 Readability tip

Use key and value when those names make the loop self-explanatory.

08 / Common Mistakes

Keys are exact

Wronguser = {"name": "Dev"}
print(user["Name"])
Correctprint(user["name"])

Dictionary keys are case-sensitive. A missing key also causes a lookup error when square brackets are used; choose get() when missing data is expected.

09 / Do & Don't

Make records predictable

Do

Use clear string keys and a consistent shape for similar records.

Don't

Mix unclear abbreviations or assume every record contains every key.

10 / What You Learned

Meaningful lookups are ready

  • Dictionaries map keys to values.
  • Square brackets read or write a known key.
  • get() provides a safe fallback.
  • Methods inspect, update, and remove pairs.
  • items() supports readable loops.
